# 2026-10-29 declared local-model listing sprint

## Slice C — exact declared model identity, still provider-free

`pipeline/document_job_model.py` parses an already-obtained bounded Ollama
`/api/tags` response for exactly one configured model. It demands exact
`name`/`model` equality, one match, a lower-case SHA-256 digest, positive size,
and `gguf` format. It rejects aliases, duplicate matches, unknown/incomplete
objects, duplicate JSON keys, non-finite values, malformed unrelated entries and
oversized input.

This is not a network adapter: it does not contact Ollama, read a service or
environment, discover/download models, inspect files, hash bytes or provide
authorization. The selected digest is only server-declared identity. It cannot
establish local execution, cloud disablement, direct transport, source consent,
or private-job readiness. `/api/show` is intentionally out of scope because
its response may disclose a model's template or system prompt.

Focused verification: six provider-free contract tests. Follow with exact
Windows-to-WSL allowlist/hash synchronization and existing focused annotation
job regression. No live provider smoke should be run for this slice.
